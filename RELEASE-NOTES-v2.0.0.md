# Pixel Suite v2.0.0

**Open Pixel Suite straight from your home screen:** touch and hold an empty area, then tap **Pixel Suite settings**—no need to find the app first.

After 45 preview updates, a lot of testing and plenty of small adjustments, Pixel Suite 2.0.0 is ready. This release brings the launcher work, screenshot tools and redesigned settings together. Thank you to everyone who helped test and report what felt wrong along the way.

## UI overhaul and smoother navigation

Everything now lives in the module app, organized into Buttons, Gestures, Pixel Launcher and Files. Each feature has its own control and explanation. Animated demonstrations show how things work, the changelog opens inside the app, and community/support links are close at hand. The interface follows light and dark mode, with cleaner menus and consistent spacing.

## Launcher and drawer refinements

Create folders directly inside the app drawer, rename them, sort their contents and add more apps. Home-screen and drawer folders have separate 3×3, 4×4 and 5×5 choices. Folder layouts, local blur, dropdowns and opening/closing transitions have been refined throughout the testing builds. The drawer keeps strict alphabetical ordering: English, Arabic, then numbers and special characters, including after removing a folder.

Dragging stays inside the drawer until you move an app to the **Add to home screen** target. Rename apps or choose custom icons through Photos or Files, and see the changes across the home screen, folders, drawer and both app searches without a manual refresh. Reset controls restore the originals.

There is also optional five-level icon-label sizing, which changes the text without resizing icons, and an option to hide app-provided drawer shortcuts. **Clear all** moves from its stock far-left position in recents and stays visible alongside **Select** and **Screenshot**.

## Gestures and screenshot tools

The flashlight, camera, screenshot, sleep and wake controls remain together with their own settings. Supported Pixel Studio versions now get free screenshot cropping and Doodles: draw shapes, adjust color and thickness, move or resize them, and use Undo/Redo while editing.

## System polish

Newest-first sorting now covers Files by Google and supported Android file pickers, keeping folders above files. Icon shapes, search updates, folder fitting and menu placement have all received attention. Feature demonstrations stop when you leave the page or the app.

## Update and setup

Install **PixelSuite-v2.0.0.apk** over the previous version and reboot. There is no need to uninstall when using the same release signature. Open **LSPosed → Pixel Suite → Scope** and check the recommended apps, including **Google** for home-screen search changes and **Pixel Studio** for screenshot editing. Configure everything in the Pixel Suite app.

Testing has focused on **Pixel 11 Pro, Android 17 and LSPosed API 102**. Pixel Studio tools target **2.3.001 (192285)**. Other devices and app versions may behave differently. Wake detection can still depend on movement and device state; there is no measured overnight battery figure for this release.
