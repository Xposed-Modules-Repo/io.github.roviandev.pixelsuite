Pixel Suite 2.0.0 is here.

After 45 preview updates and a lot of testing, this brings everything together: a redesigned settings app, drawer folders, separate folder grids, instant app renaming and custom icons across both searches, refined menus and transitions, and new screenshot crop and Doodles tools in Pixel Studio.

The goal throughout has been to make these features feel at home on a Pixel. Settings are easier to find, drawer interactions are more consistent, and the little details—icon shapes, label sizes, menu placement and folder spacing—have had a lot of attention.

Install over your existing version, check the recommended LSPosed scope, and reboot. Google needs to be selected for home-screen search changes, and Pixel Studio for the screenshot tools.

Thanks for sticking with all the test builds and helping me get this far. If something still feels off, share it in Bug Reports with your device, app version and steps to reproduce it.
